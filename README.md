# retail_project
Cree la base retail_project, en donde se crearon 3 tablas (ventas, productos y clientes), se ejecuto con script para que se visualicen.
Con BEGIN ... COMMIT se cargaron los datos iniciales que se van a ver en las columnas y un SELECT como prueba para visualizar los datos de las columnas.
Con UPDATE se aumento el precio de una categoría de productos.
Con DELETE se elimino una venta específica.
